# amandinah

A birthday surprise for Amanda (Amandinah), 15 October.

`index.html` is the whole page: she taps a gift, then her photos play like a phone story (tap to skip, hold to pause), ending with Saud's message and emoji confetti.

`photos/` holds the photos the page uses.

To put it online, enable GitHub Pages for this repo (Settings > Pages > deploy from the branch, root folder).
