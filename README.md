# amandinah

A birthday page for Amanda (Amandinah), 15 October.

- `index.html` is the whole site: a beach-day theme with then-and-now polaroids, her Libra / Periquito / volleyball / beach facts, a 15-touch volleyball game, and a birthday note.
- `photos/` holds the cropped photos the page uses.

To put it online, enable GitHub Pages for this repo (Settings > Pages > deploy from the branch, root folder).
